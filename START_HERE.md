**Q: Is my portfolio secure?**
A: Yes! No API keys, no sensitive data, HTTPS enabled automatically.

**Q: Will my portfolio be public?**
A: Yes, but only you control what goes in it. Your .git folder is public (that's normal).

**Q: Can I update after deploying?**
A: Yes! Make changes locally, commit, and push. Site updates in 1-2 minutes.

**Q: Can I use a custom domain?**
